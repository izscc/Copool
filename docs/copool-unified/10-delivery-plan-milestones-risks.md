## 10.3 风险

| ID | 风险 | 影响 | 缓解 |
| --- | --- | --- | --- |
| **RISK-01** | 种子数据中的端点/模型 ID 随时间失效 | 用户配置后调不通 | 种子只是默认值，全部可被环境变量与用户覆盖层改写（FR-PRV-06）；Doctor 的网络检查能定位到具体 provider |
| **RISK-02** | 第三方服务条款禁止复用其 CLI 登录态 | 相关能力需下线 | CLI 复用（FR-IDT-04）与订阅导入（FR-IDT-05）是 P1 且相互独立，可单独关闭而不影响 P0 主线；见 CMP-LEG-02 |
| **RISK-03** | 532pt 宽度装不下 23 家 provider 的信息密度 | 体验拥挤 | 分组折叠（CMP-01）+ 行内展开 + 专家模式；M1 完成后立即做人工验收，不合格就退回调整信息层级 |
| **RISK-04** | 去掉全目录兜底（M4-1）导致既有用户请求开始 404 | 回归投诉 | v1 路径的回落保留；404 错误体明确指出模型名与排查方式；trace 中留完整记录 |
| **RISK-05** | 推理档位不再兜底（M2-4）导致部分模型丢失档位选择 | 功能感知退化 | 种子数据已为 48 个内置模型显式声明档位；只有用户自定义 provider 的未知模型受影响，且这正是正确行为 |
| **RISK-06** | `models_cache.json` 与目标应用互相覆写形成循环 | CPU 占用、配置抖动 | 去抖 500ms（已有）+ 每分钟至多 1 次重注入限速（M3-5）+ Doctor 检查项 |
| **RISK-07** | v3 迁移在真实用户数据上失败 | 配置丢失 | 影子写 + 校验 + 备份 + 回落旧路径（MIG-01/02/04）；TST-13 覆盖崩溃中途场景 |
| **RISK-08** | 47 个既有测试因重构被误改 | 静默回归 | CI 对 `Accounts*Tests` 做 diff 门禁（TST-16 / 09.5） |
| **RISK-09** | Swift 6 严格并发在新增 actor 上报错 | 开发受阻 | ARC-02 明确并发模型；持锁方法不得互调（已知死锁即此类问题的实例） |
| **RISK-10** | M7（语音/会话）投入产出比低 | 资源浪费 | 明确排在 P0 之后，且需价值验证才启动；脚手架代码在 M0 就已清理，不留半成品 |

## 10.4 交付原则

1. **每个里程碑独立可发布**——M1 做完就应该能让用户配 DeepSeek 并在 Copool 内测试连通性，即使还不能写进 Codex 配置。
2. **先写测试再改既有行为**——M0-5/M0-6 的缺陷修复、M2-4 与 M4-1 的行为变更，都必须先有失败的测试。
3. **不为新功能牺牲既有功能**——账号池零回归是硬门槛（AC-123）。
4. **UI 约束优先于功能野心**——放不进 532pt 的功能，改信息层级，不改面板尺寸（DNA-1）。
5. **安全红线不谈判**——08 章 SEC-01..12 与实现冲突时，改实现。

# 06 · 逐屏 UI 规格

> 编号规则：`SCR-<页>-<序号>` 为屏幕，`CMP-<序号>` 为可复用组件。
> 所有尺寸受 05 章 DNA 约束：**内容区宽度 = 532 - 16×2 = 500pt**。
> 所有材质与间距走 `LayoutRules` + `SectionSurface`，不写魔法数字。

## 6.1 新增可复用组件

### CMP-01 · `ProviderGroupSection`（供应商分组折叠）

23 家 provider 一次性铺开会撑爆面板。按三组折叠：

```
┌──────────────────────────────────────────────┐
│ 已配置 (3)                              ⌄   │  ← 默认展开
│ ┌──────────────────────────────────────────┐ │
│ │ ● DeepSeek API              chat    ···  │ │
│ │   api.deepseek.com · 就绪 · 4 个模型      │ │
│ └──────────────────────────────────────────┘ │
│ ...                                          │
├──────────────────────────────────────────────┤
│ 内置供应商 (20)                          › │  ← 默认折叠
├──────────────────────────────────────────────┤
│ 自定义 (0)                    ＋ 新建     › │
└──────────────────────────────────────────────┘
```

- 复用既有 `CollapseChevronButton`（`SectionSurface.swift`）。
- 组标题右侧显示计数，折叠态不渲染子项（`LazyVStack` + 条件渲染，避免 23 张卡片常驻内存）。
- 分组容器用 `frostedRoundedSurface(cornerRadius: 12, prominent: false)`，与现有 provider 卡片一致。

### CMP-02 · `CredentialStatusBadge`（凭据状态徽章）

五态（FR-IDT-07），颜色与图标严格遵循 IA-09：

| 状态 | 展示 |
| --- | --- |
| 就绪 | 🟢 `checkmark.circle.fill` + "就绪" |
| 未配置 | ⚪️ `circle.dotted` + "未配置" |
| 已过期 | 🟠 `exclamationmark.circle.fill` + "已过期" |
| 无权限 | 🔴 `xmark.circle.fill` + "鉴权失败" |
| 校验中 | `ProgressView().controlSize(.mini)` |

**整个徽章是可点击的**——点非就绪状态直达修复动作（FR-IDT-07）。用 `AccountTagView` 的视觉规格（现有组件，`ProviderPageView.swift:309` 已在用）。

## 6.6 文案与本地化（SCR-ALL）

- 所有用户可见文案走 `L10n.tr(...)`，中英双份，**不留硬编码字符串**。
- 简体中文文案要完整——不允许出现英文导航项或英文术语混排（沿用最近提交 `224ec67` 确立的标准）。
- 技术标识（provider id、model id、文件路径、HTTP 头名）保持英文原样，不翻译。
- 错误文案三段式：**发生了什么 + 为什么 + 怎么办**。例：「无法连接 DeepSeek（连接超时）。请检查网络，或在设置中确认 Base URL。」

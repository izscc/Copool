# 22. 合规与隐私

- 本地优先：账号、凭据、会话索引和路由日志默认保存在用户设备。
- 数据最小化：Provider 请求只包含完成调用所需内容；不附加 Copool 用户标识。
- 保留策略：decision trace 默认 30 天、结构化流量指标 90 天；用户可改或立即清除。
- prompt/response 内容默认不进入通用日志；会话内容由目标应用或 Session Center 的明确设置控制。
- 音频默认不持久化。
- 导出支持包前展示包含项和脱敏预览。
- 远程节点明确数据路径、地区和传输加密；本地 Keychain secret 不自动同步。
- 供应商条款、模型许可、地区和价格由 Provider Registry 显示外部链接/更新时间，但 Copool 不替用户作法律结论。

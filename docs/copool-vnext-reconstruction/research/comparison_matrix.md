# 三项目能力对比矩阵

| 维度 | Copool(P1) | OpenCodex(P2) | Codex Router(P3) | vNext 决策 |
|---|---|---|---|---|
| 产品壳 | 原生菜单栏 SwiftUI | Swift 壳 + Node Dashboard/服务 | macOS/Tauri/CLI | 只保留 P1 SwiftUI |
| 账号池 | 强 | 弱/侧重 provider | 非核心 | P1 账号池成为 Credential Pool |
| Provider | 已有多厂商和订阅导入 | 多协议、多订阅 | 数据驱动、账单通道清晰 | Registry v2 |
| 路由 | 代理与账号切换 | 模型/Agent/工具复杂路由 | 多目标、安全路由 | 三层可解释路由 |
| 模型目录 | 已有缓存注入/发现 | 动态 catalog/能力 | 凭据感知/策展/别名 | 统一 Catalog v2 |
| 工具/CUA | Agent/代理基础 | 原生执行和图像桥 | 保留原生 Codex | ToolBridge，不自建执行器 |
| 会话 | 非核心 | 强 | 非核心 | P1 原生 Session Feature |
| Voice/Realtime | 无 | 强 | 无 | P2 插件化 |
| 安全/回滚 | Keychain/ProxyDoctor | 基础 | 强 | P3 为基线 |
| Remote | 强 | 弱 | 目标本地服务 | 升级为 Remote Node v2 |
| UI 容量 | 固定小面板 | 大 Dashboard | Tray/Desktop | 5 Tab + drill-down |
